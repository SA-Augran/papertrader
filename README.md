# Papertrader

**给 AI 伙伴一笔模拟资金，观察它如何判断、经营与积累经验。**

Papertrader 是一个面向个人 Agent 与 AI 伙伴的 A 股模拟交易环境。它为你已有的 AI 提供一个长期账户，让它跟随真实交易日查看行情，在交易纪律内自主选择买入、卖出或观望。你可以通过本地网页查看持仓、追踪决策，并观察交易经历如何影响后续的策略选择。

一次买入会延续为持仓、等待、卖出与反馈。每轮持仓全部卖出后，系统将扣除费用的实际盈亏归回开仓策略，更新后续选择偏好。随着记录积累，同一个账户里的决定与结果形成连续的经营经历。

A local A-share paper-trading environment for personal AI agents, with outcome-based strategy learning, traceable decisions, a web dashboard, and HTTP / MCP integration.

## 可以观察什么

- **它何时行动，又为何等待。** 从账户看板进入一笔决策，查看当时的提案、纪律检查与成交结果，沿着流水跟进一轮持仓。
- **经历怎样影响下一次选择。** 完整平仓后的净盈亏更新对应策略的经验记录，Thompson 采样据此分配后续候选策略的开仓机会，同时保留探索机会。
- **说过的话怎样约束行动。** 对指定股票作出的明确观望承诺会参与开仓检查，修改承诺时保留原话与理由。
- **同一提案在另一条件下如何被检查。** 复核页可以选日期和决策，重算保存的检查，或暂不应用观望承诺后比较结果。成交与盈亏展示原始记录。

适合想为已有 AI 伙伴增加一项长期活动的人，也适合对 AI 决策与学习感兴趣的观察者。可以先在网页体验本地模拟，再接自己的 Agent，或配置模型 API 交给内置运行器。

项目包含账户服务、网页、HTTP 接口与可选 MCP 适配器。角色设定、记忆与唤醒时机由你自己的 Agent 管理。

## 快速启动

需要 Python 3.9 及以上。解压源码或克隆仓库后，在项目目录执行下面两行。安装完成后，本地体验无需行情 API、模型密钥或外网。

```sh
python -m pip install .
python -m papertrader serve --mode local --sandbox --data-dir ./sandbox-account --open
```

网页打开后，到「关于」页点「执行一次」。沙盒使用明确标注的合成行情，通过手动触发做一次决策。看板和流水会显示这次活动。界面、字体与图表均使用本地资源，无需 CDN。

### 使用真实日线

```sh
python -m pip install -e ".[realmarket]"
python -m papertrader serve --mode external --data-dir ./account --open
```

--open 会在本机打开并登录面板，令牌从地址栏移除并仅保存在浏览器会话。也可手动打开终端显示的 http://127.0.0.1:8322，输入 Account token。保持进程运行，上海时间 19:30 后每 10 分钟检查当日行情，准备任务等待 Agent 提交。

真实行情需要网络。行情缺失或过期时等待并显示错误，服务不会自动切换合成数据。用户提供 CSV 时用 --csv 指定，日期、来源和沙盒状态会显示在面板。

切换模式或数据来源时，请使用新的账户目录。日常经营按真实交易日运行，历史测试用于验证。

## 接入自己的 Agent

账户服务提供行情、持仓、当天允许的行动与过往反馈。宿主负责定时唤醒与模型推理。它先取当日任务，再提交买入、卖出或观望，之后可把完整平仓的结果写回自己的记忆。

- **HTTP**。先读取 /api/context，保存任务 ID 与自己的提案，再调用 /api/submit。examples/host_agent.py 提供标准库示例。
- **MCP**。使用 Python 3.11 及以上，安装 `python -m pip install -e ".[mcp]"`，配置宿主以 `python -m papertrader mcp` 启动 stdio 适配器，并设置 PAPERTRADER_URL 和 PAPERTRADER_TOKEN。
- **Python**。Simulator 支持 proposer 回调，直接嵌入自己的程序。

MCP 提供八个工具，读取账户、获得当日任务、提交决策、拉取反馈、管理明确承诺、提交背景信息与复核记录。宿主负责定时唤醒和记忆写入，MCP 连接本身不会自动经营账户。

完整配置、工具、HTTP 字段、宿主指令和重试方式见 [接入说明](docs/接入说明.md)。

## 没有现成宿主时

安装模型与行情依赖。

```sh
python -m pip install -e ".[llm,realmarket]"
python -m papertrader serve --mode model --data-dir ./account
```

启动前将模型密钥配置为环境变量，或按 .env.example 在账户目录创建 .env。主模型默认使用 ZHIPU_API_KEY，备模型使用 DEEPSEEK_API_KEY，可配置地址和模型名。--persona 可指定用户自己的角色文本。没有提供凭据的 model 模式会明确报错。

--mode local 显式使用本地规则。已有 Agent 模式不调用内置语言模型。

## 技术结构

```text
个人 Agent 或内置模型运行器
          │
     HTTP / MCP / Python
          │
行情事实 → 策略候选与抽样授权 → Agent 提案
                                  │
                         承诺与纪律检查
                                  │
                           SQLite 模拟账本
                                  │
                    整轮平仓 → 原策略反馈
                                  │
                    下一次偏好、纪律与经验
```

- **自主判断与授权机会**。Thompson 采样在有候选的趋势与回调策略间分配机会，Agent 可以主动观望或卖出。新策略注册接口尚待实现。
- **反馈有时间和对象**。整轮平仓扣除费用后，更新实际开仓策略。浮盈、观望和拒单不计入结算奖励。
- **承诺影响行动**。显式承诺约束指定标的新开仓，改口保留原话和理由，执行时重新检查。
- **可追踪与可复核**。任务、提案、检查、成交和学习记录相连。保存的快照可以复算原检查或移除一条等待承诺，假设盈亏尚未模拟。
- **模型分层**。主模型、备模型、本地规则依次降级。来源进入记录，语言模型权重保持不变。
- **独立运行**。一个服务持有一个账户数据库。持久任务支持重启与重复提交恢复，多个接口共用状态，不另开决策账户。

## 网页面板

网页包含看板、流水、成长、复核和关于五个分区。看板展示资金、持仓、自选快照和资产曲线。流水可展开提案、检查与结算。成长页展示当前生效的交易纪律。

复核页提供顶部日期与决策选择、双周交易刻度、规则版本和资产曲线。快照复核支持重算原检查，也支持暂不应用观望承诺，比较同一提案在两种条件下的检查结果。复算范围是提交检查，成交与盈亏读取原始记录。

样式、背景和 ECharts 5.5.0 均随包提供，无字体或图表 CDN。第三方图表许可见 papertrader/web/vendor/LICENSE 与 NOTICE。暂停、恢复和连接管理位于关于页。

账户访问令牌保存在本地账户数据库。浏览器仅在当前会话保存令牌。数据目录和模型配置均不应提交到 Git。

## 验证与打包

```sh
python -m unittest discover -s tests -v
python scripts/evaluate.py --output evaluation.json
python scripts/build_release.py --output dist
```

MCP 可选依赖安装后，测试包含真实 stdio 握手与工具调用。CI 检查 Python 3.9 与 3.11。发行打包使用文件白名单，排除数据库、私有部署文件、旧构建与内部运维材料，生成源码 ZIP、清单和摘要。发布前仍需检查实际 Git 历史。

历史回放可用 scripts/prepare_demo.py 与用户提供的 CSV 重新生成。真实行情再分发前应核对上游许可，因此公开源码包不附带个人行情缓存。

## 当前边界

服务默认仅监听本机，首版为单用户。实时服务按信号日收盘价简化成交，每边 10 基点费用，允许碎股。独立评测脚本使用下一收盘价撮合。尚未完整模拟整手、T+1、停牌排队、涨跌停、分红与拆股。

服务停机期间不会调用 Agent，也不会恢复后伪造过去的决策。账户目录使用单服务所有权锁，不能同时由其他程序直接修改数据库。写事务保证成交与结算的一致性，仍应定期备份。

通用接口、基础面板和本地机制可复现；真实在线模型的判断质量与投资表现没有保证。现有对照没有证明 Thompson 带来股票收益优势。

## 扩展

角色文本、模型提供方和前端均可替换。宿主 Agent 可以将已结算交易反馈写入自己的长期记忆，也可以通过背景信息接口提交自主搜索所得的内容，丰富下一次判断的上下文。记忆管理、搜索和定时唤醒由宿主实现。

动态策略注册、更完整市场模拟、多用户托管与更广泛样本外验证为后续方向。
